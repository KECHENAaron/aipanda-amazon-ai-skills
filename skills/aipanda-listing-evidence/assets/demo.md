# 完全合成练习导览

本包仅用中性编号和独立构造的测量值，不映射实际商品、店铺或经营资料。当前 JSON 协议见 [契约](../references/contract.md)。

- [supported](supported.json)：由 scripts/make_demo.py 公开常量生成。
- [conflicts](conflicts.json)：由 scripts/make_demo.py 公开常量生成。
- [boundaries](boundaries.json)：由 scripts/make_demo.py 公开常量生成。

程序只检查结构化输入，不验证外部事实或自然语言语义。来源与许可见 [说明](../references/sources.md)。
