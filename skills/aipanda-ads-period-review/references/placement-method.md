# 广告位：同口径比较，注意乘数与流量组成

先使用同一个活动、期间、币种、归因和快照的广告位报告，分别重算 top / rest / product 的 CPC、订单 / 点击与 ACOS。没有该层数据就不从总 ACOS 猜哪个位置应加价；低样本也不能当成稳定优势。

三个广告位必须是互斥且同范围的分组，合计与日级控制摘要一致。其他站外或特殊视图不硬塞进这三组；缺位、重叠、未知或不齐都保留问题。源报表并非一定只有三种视图，协议只覆盖明确声明的简化分区。

配置层看基础竞价和广告位乘数的共同效果。某一项上调的百分比不等于最终组合变化；二者同时改动会相乘。实际 CPC、赢得展示和未来转化也不会按该乘数等比例变化。

广告位加价、动态竞价、受众、日程和其他调整可能共同影响最终出价。该脚本只展示 fixed、统一基础竞价、无其他加价声明下的乘数算术；其余情景显示未知，不把固定公式套到动态策略。0–900 的输入范围是本模型范围，不代表已经核实实际账户上限或可用性。

增加位置调整时，本协议要求该位的成熟样本和目标内效率；降低则要求所选指标支持的偏离。即使通过，仍只得到 REVIEW_ONLY。不能仅因某位历史 ACOS 最低就宣布它最值得放量；目标、流量组成和试验条件仍须人工解释。

同时改变多个广告位也是多变量。若要有意联合调整，需另设计可解释的试验；本脚本不支持把联合结果归因于某一个变量。
