# 广告复盘通用方法卡

本卡把经用户授权的课程学习摘要与内部复盘笔记重新整理为通用问题，不附原件、专属表格、案例或经营数值。来源性质与许可边界见 [sources](sources.md)。它指导人工解释，不扩大脚本的确定性能力。

## 先说明这次广告要完成什么

在使用者本地记录本轮目标、观察阶段和广告角色。例如验证新流量、承接已有需求或保护已确认的需求。不要仅凭上架时间给阶段下结论，也不要为了套角色清单新开活动。公共报告使用匿名标签，不附实际对象与标签的映射。

## 先定位层级，再解释指标

先看所选范围，再看不同广告单元对总量和效率的贡献。整体变差可能来自单元内变化，也可能来自组成变化；整体变好也不代表每个单元都改善。各层重复汇总视图不能相加；无法确认某笔表现属于哪个对象时保持未分配，不人为摊给商品。

周期脚本实现两期日级摘要，新增诊断脚本用匿名匹配类型、角色、TERM / TOKEN 与承接声明检查候选。真实搜索词语义、广告位、小时、当前竞价和自然排名没有进入协议；不能声称程序已经解释到这些层。

## 把活动和恢复期分开看

活动前、活动中、恢复阶段分别保留窗口与事件。脚本一次比较两期，可以在本地分别比较“活动前 / 活动中”和“活动前 / 恢复期”；两次结果不能相加。活动期出现的峰值只是一段观测，不自动成为长期目标。没有真实小时数据就停留在日级，不从操作时间戳造小时表现。

## 用可被推翻的假设写结论

把“现象、可能解释、缺什么证据、怎样验证”分开。促销、价格、可售状态、内容和竞价同时变化时，描述相关变化并列出替代解释。若要检验原因，应另设计单变量或适当对照，保留观察窗口与停止条件；周期前后差不能单独证明因果。

## 让建议停在证据支持的范围

零订单可以来自样本不足、回填未完成、关联范围错误或承接问题，不自动等于无效流量。高 ACOS 需要看目标、规模和来源；低 ACOS 也不自动意味着应增加预算。固定点击门槛、暂停线和调价比例都需另行校准。该公开包只输出复核问题，不做利润核对或后台操作。
