# 搜索词、符号聚合与样本诊断

方法背景参考经授权的学习卡及公开的特征词分析文章。此处采用本项目独立编写的算法，未移植文章代码、数据表或固定阈值。

完整搜索词是复核单位，投放来源是边界。相同完整词的不同来源事件可以并列；同一来源、同一窗口被重复导出的记录不能再计一次。脚本仅接受匿名 TERM 与源 UNIT，source_row 和 row_id 保留追溯。真实词及映射只留在本地。

query 与 product_target 分开。商品目标不进入词根表，也不变成关键词否定。tokens 是人工提供的匿名符号序列，不是 NLP 的语义判断；真实词的词形、近义、品牌与意图归类需要另行审核。

每条源记录对一个单符号只贡献一次；双符号只取原序列中相邻的组合，并按源记录去重。重复词根不倍增本行指标；不拼造不相邻的组合。一个完整词可能属于多个组，因此单词根、双词根视图不能相加当总量。先回查完整 TERM 和全部来源，再提出候选，不能从词根好坏批量否定。

诊断先区分缺失、归因未成熟、低样本、零订单复核、有订单但效率待查与需要保留观察。目标 ACOS、最低点击 / 订单和复核花费线必须显式配置，仅是当次筛选假设，不是课程或平台的通用门槛。零销售额时 ACOS 未定义，不标为健康；订单 / 点击和 CTR 等比率都由聚合分子分母重算。

任一来源已经有订单，或用户显式保护该 TERM，都会阻断普通否定候选。其他来源转化未知、数据矛盾时也不能当作零成交。相关性声明若与成交信号矛盾，保留矛盾供人工回查，不由程序宣布产品不相关。

phrase 否定涉及真实语义、词序与平台匹配规则，本包不把匿名 token 匹配当作真实平台命中测试。遇到现有 phrase 否定时保留人工语义复核阻断。
