# 候选判断边界

阈值来自上游启发式默认值，可通过config调整，不代表所有类目的统计置信区间或盈亏线。

逐日模式以真实日期构建窗口；记录覆盖不足时披露，不假定缺失日期为零。汇总模式仅比较本窗口的词、ASIN参考CVR/ACOS与用户明确目标，不计算伪短期趋势。

没有完整订单或销售额时只做语义与流量观察，不能把未知视为零单。ACOS参考线不是利润线，未核实成本不可声称亏损。低样本即使CVR高也保持测试。

词类和Listing匹配属于启发式候选；未经核实的竞品词、产品材质与适龄信息需人工核对。所有出价、放量、否定均为候选，不写后台。

保护词来自本次config，品牌偏好、Vine/SBV偏好和阶段策略不自动继承作者或其他Skill。
