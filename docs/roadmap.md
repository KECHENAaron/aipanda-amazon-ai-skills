# 发布路线

## 当前：0.7.0

7 个技能入口，4 个 MIT 技能与 3 个 AGPL 社区包；9 个完全合成案例主题。广告复盘 Skill 1.2.0 包含三种独立协议，共 10 个常量练习：周期比较、架构 / 搜索词诊断、竞价 / 预算 / 广告位情景。
