# 发布路线

## 当前：0.1.0 基础版

- 搜索词离线复核：标准 CSV、范围校验、归因成熟度、来源行号、HTML 与 JSON。
- Listing 证据复核：指令型技能与合成案例。
- 竞品证据对标：指令型技能与合成案例。

## 下一批候选

- 多种真实导出格式的显式字段映射器，保留原始口径。
- 广告前后比较：统一期间和实际投放天数，披露样本与干扰因素。
- 利润核对的合成账例：区分结算、成本、库存与现金流。
- Listing 事实对照的结构化输入和机器校验。

## 后续研究

选品研究、知识检索、报表模板与可验证的自动化。数据接口、付费服务及生产执行能力暂未接入；只有独立验证并公开说明边界后才进入正式功能目录。

路线图表达方向，不是交付时间或效果承诺。更新以实际版本为准。
