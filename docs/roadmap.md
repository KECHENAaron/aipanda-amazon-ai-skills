# 发布路线

## 当前：0.2.0

3 个 MIT 基础技能 + 3 个 AGPL 社区衍生包，4 个合成重构案例。可运行能力涵盖标准 CSV 搜索词复核、搜索词进阶分析、Listing 结构化事实审计、图片简报与可选像素筛查；另有 2 个指令型工作流。

完整目录见 [README](../README.md)，筛选与暂缓原因见 [公开内容筛选记录](curation.md)。本版不连接账户或写后台。

## 下一批优先方向

1. 广告前后比较：统一期间、实际投放天数、归因成熟度、分母与干扰因素，再设计合成练习。
2. 合成利润核对：区分结算、成本、库存和现金流，避免导出真实账本。
3. 多种报表输入契约：扩充显式字段映射与负例，仍保留原始口径。
4. 工作簿技能：先核验模板与引用许可、依赖、公式和重算路径，再决定是否发布。

## 后续研究

选品研究、知识检索与模拟接口。付费课程原文、私有 RAG、真实经营报表、凭据与生产接口配置不在公开范围。功能只有通过独立验证并写清边界才进入目录。

路线图表达方向，不是交付日期或效果承诺。
