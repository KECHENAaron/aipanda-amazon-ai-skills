1. 竞价：历史 CPC 不等于基础 Bid

合成历史 CPC 约 0.6667，声明基础竞价 0.8，目标成本 CPC 参考为 1.0。提议将基础值改为 0.9，保持 top 加价 25% 不变；简化固定情景从 1.0 到 1.125。三个数各有含义，参考值不作为盈亏点或推荐 Bid，也不预测下一期转化。

2. 预算：低 ACOS 还需要约束证据

平均日预算假设从 20 改为 24，另声明 3 天出现预算约束，效率、样本与承接条件在本例下支持复核。去掉约束信号或改成未知会被阻断。这里没有把日花费达到预算当作耗尽证明，更没有把 24 当每日花费硬上限。

3. 广告位：加价翻倍，情景 Bid 不翻倍

保持基础值 0.8，将 top 加价从 25% 改为 50%，固定乘数情景从 1.0 到 1.2，即增加 20%。各位历史表现、样本与范围对账分别保留。示例不是在宣布 top 最优，也不会按某位最低 ACOS 自动选择放量位置。

4. 联合改动：变化相乘，不能简单相加

基础值改为 1.1、top 加价改为 75%，同时修改预算。固定情景由 1.0 变为 1.925，增加 92.5%；超过本例声明的 1.5 情景边界，且多变量同时变更，候选均被阻断。该边界只属于合成设定，不是平台上限或通用建议。
