04 / IMAGE WORKFLOW · 实务问题重构

简报通过，距离成图还有几步。

配件、尺寸与比较图，每张图都要对上事实。

实务中的问题

图片计划里写好了卖点，却没有当前配件清单、参数仍有争议，或比较图缺少对照依据。即使计划写满七张，也可能无法据此安全制作图片。

本例完全重写为合成收纳箱简报，不公开原产品图片、产品结构或经营资料。当前没有调用生图工具，也没有上传图片。

先运行有问题的简报

槽位检查发现结果
1 / 主图展示配件但未绑定当前随箱清单blocked
2 / 尺寸SIZE 仍有冲突blocked
3 / 比较缺 comparison_evidenceblocked
4 / 随箱物缺 current BOMblocked

然后收窄为有依据的草稿

修订输入仅保留白底主图计划与折叠结构购买疑问，不展示额外配件，不写未经核实的尺寸，不做无来源比较。两槽位简报返回 BRIEF_CHECKED_DRAFT，每张仍为 ready_for_design_review。

七槽位是建议结构，实际可以两张或更多。删去缺证卖点让简报可继续设计，不能被描述为冲突已经解决。

怎样复现

按 图片包公开练习分别运行 blocked 与 revised 两份输入。

原简报阻断结果修订简报修订结果

验收状态要逐层说清

简报检查 → 实际出图 → 技术筛查 / OCR → 实物与文字人工核对 → 按当前站点类目规范复核 → 授权上传。这些是不同状态。本次两份运行均为 generated_images=0、uploaded_images=0、business_writes=0。

即使未来像素检查发现白色边缘，也不能自动证明整张图背景、产品占比、商品身份或平台合规。包内的 Pillow 检查保留人工复核状态。
