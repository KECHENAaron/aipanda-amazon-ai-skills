# 公开分享规范

本项目只分享通用技能、代码、公开方法定义与完全合成练习。不发布商品名称 / 实际 ASIN / SKU / 规格、品牌 / 店铺 / 账户、原图、成本费用、利润账本、订单、客户、内部部署、会话或知识库资料。利润核对不属于本项目的发布方向。

## 样例要求

优先使用常量独立生成，不从真实报表抽样、缩放、换名或保留可逆映射。公开数据显式声明 synthetic；标签使用 DEMO、UNIT 等占位。金额只能是为验证公式而设的演示数。仅声明 synthetic 不足以证明已经脱敏。

## 来源要求

新编写的匿名广告周期 Skill、基础工具及原创练习适用 MIT。IvyeaOps 社区衍生包与 `docs/cases/data/` 保留完整 AGPL-3.0、作者、固定提交与改动说明；不按根 MIT 重新授权。品牌图片另见 NOTICE。

课程与内部知识卡经授权可以提炼成重新编写的通用方法，并保留来源性质说明；不附经营数据、原卡片或内部路径。来源混合或许可不明的实现、原文、素材和模板不整包搬运；独立编写的公开实现需能够单独解释与验证。拥有本机副本不代表有再分发权。

## 发布检查

先人工审阅实际文件、标识、数值、图片与来源，再运行测试、合成生成器对照和 `python3 tools/check_public_release.py --history`。检查器只报告规则与位置，不回显匹配值；历史扫描包括本地已获取的公开分支 / 标签可达对象。模式扫描辅助人工复核，不提供绝对无泄露保证。

不把真实业务输入、输出或截图提交到公开仓库或 Issue。匿名本地输入生成的报告标为“不供公开”。发布审批不会因安装某个 Skill 自动延伸到数据上传或业务后台执行。
