v0.3.0 历史复审记录

检查了什么

  • 主项目发布前历史基线：96 个唯一文本 Blob、5 个提交；个人主页基线：5 个文本 Blob、4 个提交。检查当前文件，并扫描本地已获取公开分支 / 标签可达的历史对象与提交文本。
  • 确认主项目与个人主页各仅有 main 分支；主项目没有 Releases 附件、Issue 或 PR 内容。
  • 复核产品标识占位、品牌与数据声明、原始报表 / 数据库 / 会话等不允许的附件、路径和凭据模式；不在此记录中附真实标识、敏感词典或内部文件路径。
  • 仅有品牌熊猫头像作为二进制图片。检查当前元数据：无 GPS、无可读 IPTC 记录，EXIF 仅分辨率、方向、色彩与图像尺寸；画面不含实际商品。
  • 检查原有 MIT / AGPL 许可分区、上游署名、来源与改动记录。新匿名广告 Skill 的代码与合成输入独立编写，方法卡经授权重构，原课程及知识卡不随包分发。

调整了什么

  • 基础搜索词练习统一为中性 DEMO 词，报告、输入与测试一并更新。
  • 公开介绍聚焦技能与完全合成练习，撤下内部候选清单及利润核对计划。
  • 新增匿名广告协议，拒绝商品、店铺、成本或自由备注等额外字段；匿名本地报告标记“不供公开”。
  • 新增发布模式检查器与反例测试；三个广告练习与常量生成器逐项一致，六个输出文件重跑一致。

复核边界

数据标记 synthetic 本身不能证明没有泄露。模式检查辅助人工审阅，不能识别所有隐含关联、任意费用数字或截图中的语义。没有将真实资料换名、缩放或抽样后发布；保留的金额、规格与标签均为独立练习设定。
